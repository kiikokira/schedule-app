# iPhone での利用手順

1. 公開後の URL（https://kiikokira.github.io/schedule-app/）を iPhone の Safari で開く
2. Safari の共有ボタン →「ホーム画面に追加」→「追加」
3. ホーム画面のアイコンから起動（フルスクリーン・オフライン対応）

# 参考書の追加方法

「＋ 参考書を追加」画面には2つのタブがあります。

- **参考書一覧**: 主要な英語の参考書（英単語・文法・構文・長文・英作文）が登録済み。
  タイトル欄で絞り込み、候補から「選ぶ」をタップするとページ数・科目・表紙が自動で入力されます。
  オフラインでも利用でき、確実に追加できます。
- **Google Booksで検索**: タイトルで検索して候補から追加できます。
  検索が失敗する日もあります。その場合は参考書一覧から選んでください。

検索せずに、直接タイトル・ページ数などを手入力して「登録する」こともできます。

# 学習スケジュールでまとめて登録

ホーム画面の「スケジュールで参考書を追加」をタップすると、高2春休み前〜高3夏休み中までの勉強計画が表示されます。

- 各フェーズ（高2春休み前 / 高2夏休み前 / 高2夏休み中 / 高2冬休み前 / 高3春休み前 / 高3夏休み前 / 高3夏休み中）に参考書と期限日が組になっています。
- 「このスケジュールで登録する」をタップすると、まだ登録されていない参考書を**開始日＝今日・期限=スケジュールの期限**で追加し、登録済みの参考書は**期限だけを更新**します（進捗や開始日は保持されます）。
- LEAPや速読英熟語のように複数フェーズに登場する参考書は、最後（最新）の期限が設定されます。
- 以前に参考書一覧から追加した本はタイトルが一致すれば紐づきます。

# Google Books 検索の精度を上げる（APIキー設定）

Google Books の検索は、無料の **APIキー** を設定すると、検索できない・精度が低いといった問題を回避しやすくなります（設定しなくても動きます）。

## APIキーの発行手順

1. [Google Cloud Console](https://console.cloud.google.com/) に Google アカウントでログイン
2. プロジェクトを選ぶ／新規作成する（無料のプロジェクトでOK）
3. メニュー →「APIとサービス」→「ライブラリ」→「**Books API**」を検索 → 「有効にする」
4. メニュー →「APIとサービス」→「**認証情報**」→「認証情報を作成」→「**APIキー**」
5. 表示されたキー（例: `AIzaSy...`）をコピーする

## アプリへの設定

1. アプリの「設定」画面を開く
2. 「Google Books 検索」欄の入力ボックスに APIキーを貼り付ける
3. 「APIキーを保存」をタップ

> APIキーはこの端末のブラウザ内（localStorage）にのみ保存されます。サーバーには送信されません。

# 表紙画像について

参考書一覧の表紙は、版元ドットコム（hanmoto）や出版社公式の画像URLを `src/data/catalog.ts` の `coverSrc` に設定して表示しています。
画像の表示に失敗する本は、自動的にプレースホルダ（未設定）表示になります。
詳しくは `public/covers/README.md` を参照してください。
