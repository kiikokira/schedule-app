# iPhone での利用手順

1. 公開後の URL（https://kiikokira.github.io/schedule-app/）を iPhone の Safari で開く
2. Safari の共有ボタン →「ホーム画面に追加」→「追加」
3. ホーム画面のアイコンから起動（フルスクリーン・オフライン対応）

# 参考書の追加方法

「＋ 参考書を追加」画面には2つのタブがあります。

- **参考書一覧**: 主要な英語の参考書（英単語・文法・構文・長文・英作文）が登録済み。
  タイトル欄で絞り込み、候補から「選ぶ」をタップするとページ数・科目が自動で入力されます。
  オフラインでも利用でき、確実に追加できます。
- **Google Booksで検索**: タイトルで検索して候補から追加できます。
  検索が失敗する日もあります。その場合は参考書一覧から選んでください。

検索せずに、直接タイトル・ページ数などを手入力して「登録する」こともできます。

# 表紙画像の設定（任意）

カタログの参考書に表紙画像を追加できます（画像を追加しなくてもアプリは正常に動きます）。

1. 画像ファイルを `public/covers/` フォルダに入れる（GitHub の画面で `public/covers/` →「Add file」→「Upload files」。ファイル名は半角英数字、縦横比 約3:4 を推奨）
2. `src/data/catalog.ts` で対象の参考書に `coverSrc` を指定する

```ts
// 例: public/covers/polaris1.png を置いた場合
{
  id: 'eibunpo-polaris-1',
  title: '英文法ポラリス1 Final',
  subject: '文法',
  totalPages: 360,
  coverSrc: 'covers/polaris1.png',
},
```

画像を指定した本は、追加画面の一覧・ホーム画面のカード・詳細画面のすべてで表紙が表示されます。
未指定の本にはプレースホルダ（未設定）表示が出ます。

詳しい手順は `public/covers/README.md` にも記載しています。
