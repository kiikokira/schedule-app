# 罰・取り返しセンター Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** その日の記録漏れに罰（借金・罰Pt・ランク・履歴・通知）を与え取り返しを促す

**Architecture:** 純粋判定 `lib/penalty.ts` + Dexie v6 `penalties` + `data/penaltyStore.ts` 評価層 + Home/Todayバナー + 新画面 `PenaltyScreen` + 起動時通知。自動割当は変えず表示のみ。

**Tech Stack:** React + TypeScript + Vite, Dexie.js IndexedDB, Vitest + Testing Library, ntfy via existing notify utils

**Spec:** docs/superpowers/specs/2026-11-17-penalty-design.md

## Global Constraints

- TDD必須。先に失敗テストを書きRED確認してから実装。reportにRED/GREEN証拠を残すこと
- テスト実行はworktreeでのみ行うこと。コマンド例: `& "C:\Program Files\nodejs\npm.cmd" test -- src/lib/penalty.test.ts --run`。プロジェクトルートから実行し `.worktrees` / `.superpowers` 配下の重複テストを除外し React duplicate-copyエラーを避けること
- 日本語UI維持。data-testidは各タスクの指定値を一字一句そのまま使うこと
- 既存パターン遵守: 開閉ボタン、window.confirmはvi.spyOn、localStorage/fake-indexeddb使用。YAGNI（計画外の機能追加禁止）
- PDF・jpg等のバイナリをコミットしないこと。1タスク1コミット以上すること
- 既存の記録動作を壊さないこと: `useRecords/addProgress`、`useCycleRecords/addCycle`、`generateDayPlan` の振る舞い維持
- コミット・push・PRはcontrollerが行う。implementerは指定branchにコミットまで、pushはしないこと
- ベースライン厳守: `src/screens/HomeScreen.test.tsx` のNOW系テストは時刻依存で揺れるため触らないこと

## Review Focus

- focus期間外の本が罰判定に混ざり誤検出する → 対象外は常に除外されること
- 計画なし日（空き時間ゼロ・対象本ゼロ）がサボり扱いされstreakが切れる → 計画なしは判定スキップされること
- 借金が7日超で消えるか残るか曖昧で無限に膨らむ → 直近7日合算・上限500が守られること
- severity切替で過去のpointsが遡及変更される → 過去分は当時のseverityで固定されること
- 遅延記録（翌日に前日分を記録）で罰が消えない → 次回評価で上書き・残高減算されること

```ts
// src/data/penaltyStore.test.ts
import { describe, it, expect, beforeEach } from 'vitest'
import { db } from '../db/database'
import { evaluateDay, listPenalties, getPenaltySettings, setPenaltySettings } from './penaltyStore'
beforeEach(async () => { await db.penalties.clear(); localStorage.clear() })
describe('penaltyStore', () => {
  it('未記録があれば保存される', async () => {
    const e = await evaluateDay('2026-11-14', ['a','b'], new Set(['a']), [{bookId:'a',pages:10},{bookId:'b',pages:20}], [], 'normal')
    expect(e?.missingBookIds).toEqual(['b']); expect(e?.pageDebt).toBe(20); expect(e?.points).toBe(10)
    expect(await listPenalties()).toHaveLength(1)
  })
  it('全記録ならnullで保存しない', async () => {
    const e = await evaluateDay('2026-11-14', ['a'], new Set(['a']), [{bookId:'a',pages:10}], [], 'normal')
    expect(e).toBeNull()
  })
  it('同日再評価は上書きで1件のまま', async () => {
    await evaluateDay('2026-11-14', ['a'], new Set(), [{bookId:'a',pages:10}], [], 'normal')
    await evaluateDay('2026-11-14', ['a','b'], new Set(), [{bookId:'a',pages:10},{bookId:'b',pages:5}], [], 'normal')
    expect(await listPenalties()).toHaveLength(1)
  })
  it('遅延記録で解消され削除される', async () => {
    await evaluateDay('2026-11-14', ['a'], new Set(), [{bookId:'a',pages:10}], [], 'normal')
    const e = await evaluateDay('2026-11-14', ['a'], new Set(['a']), [{bookId:'a',pages:10}], [], 'normal')
    expect(e).toBeNull()
    expect(await listPenalties()).toHaveLength(0)
  })
  it('別日はseverityが遡及変更されない', async () => {
    await evaluateDay('2026-11-13', ['a'], new Set(), [{bookId:'a',pages:10}], [], 'mild')
    await evaluateDay('2026-11-14', ['a'], new Set(), [{bookId:'a',pages:10}], [], 'strict')
    const all = await listPenalties()
    expect(all.find(p => p.date === '2026-11-13')?.points).toBe(5)
    expect(all.find(p => p.date === '2026-11-14')?.points).toBe(20)
  })
  it('設定の既定はnormal', () => { expect(getPenaltySettings().severity).toBe('normal') })
  it('severityを保存できる', () => { setPenaltySettings({severity:'strict',enabledBanner:true}); expect(getPenaltySettings().severity).toBe('strict') })
})
```
