# Carousel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ホーム画面のNOW・NEXTの下に今日の続きキューの自動再生カルーセルを追加する

**Architecture:** 汎用 `Carousel`（状態＋タイマー＋touch）に薄い `HomeQueueCarousel` 結合を載せる。新規依存なしで `HomeScreen` の予定データを流用する。

**Tech Stack:** React 18 + Vite + TypeScript, testing-library/react, vitest, 既存 `CoverImage`・`styles.css`

**Spec:** docs/superpowers/specs/2026-11-23-carousel-design.md

## Global Constraints
- 新規依存を追加しない（Embla/Swiper等は使わない）
- 自動再生の既定は `autoPlayIntervalMs = 5000`、ループする
- hover / focus / touch操作中は自動再生を一時停止する
- `prefers-reduced-motion: reduce` では自動再生・transitionを無効化する
- 360px幅で はみ出し・折返し崩れを起こさない（固定幅なし・max-width 100%）
- 矢印・ドットは `button`、aria-labelは `前へ`・`次へ`・`${i+1}枚目に移動`
- test-idは `home-queue-carousel`, `carousel-prev`, `carousel-next`, `carousel-dot-N` を使う
- 表紙表示は既存 `src/components/CoverImage.tsx` を再利用する
- 変更前に `npm run build` が通ることを確認し、対象ファイルのみコミットする

## Review Focus
- 空キュー（予定がNOW/NEXTのみ）のときカルーセルが出ずホームが壊れない → Task 2のテストで固定する
- 1件のみのとき矢印・ドットなしの1枚表示でタイマーが回らない → Task 1のテストで固定する
- 画像URLが壊れている・nullのときプレースホルダで崩れない → Task 2のテストで固定する
- 矢印連打＋自動再生タイマーが競合してindexが範囲外にならない → Task 1のテストで固定する
- アンマウント後にタイマーが残りsetState警告が出ない → Task 1のテストで固定する

### Task 1: 汎用 Carousel component

**Files:**
- Create: `src/components/Carousel.tsx`
- Test: `src/components/Carousel.test.tsx`

**Interfaces:**
- Consumes: なし（Reactのみ）
- Produces: `export type CarouselProps = { itemCount: number; renderItem: (index: number) => React.ReactNode; autoPlayIntervalMs?: number; ariaLabel?: string; onIndexChange?: (index: number) => void }` と `export default function Carousel(props: CarouselProps)`。`autoPlayIntervalMs` 省略時は `5000`。`itemCount <= 1` のとき矢印・ドット非表示かつタイマー停止。外側 `section` は `data-testid="carousel"`、矢印は `carousel-prev` / `carousel-next`、ドットは `carousel-dot-N`（`aria-label="${N+1}枚目に移動"`、`aria-selected` 付き）。

    expect(screen.getByText('card-1')).toBeInTheDocument()
    fireEvent.click(screen.getByTestId('carousel-dot-2'))

- [ ] **Step 3: Implement `Carousel(props: CarouselProps)` in `src/components/Carousel.tsx`**

内部 `index` state＋`useEffect` タイマー（`(index + 1) % itemCount`）。hover/focus/touch中は停止フラグでスキップ。touchは `onTouchStart`/`onTouchEnd` の `clientX` 差が30px以上で前後移動。`matchMedia('(prefers-reduced-motion: reduce)')` が真ならタイマー無効。クリーンアップで `clearInterval`。矢印・ドット操作後はindex更新＋`onIndexChange` 呼出。

- [ ] **Step 4: Add tests for autoplay loop + swipe + single item + unmount**

```tsx
it('auto-plays and loops with fake timers', async () => {
  vi.useFakeTimers()
  try {
    render(<Carousel itemCount={2} renderItem={(i) => <div>card-{i}</div>} autoPlayIntervalMs={5000} />)
    expect(screen.getByText('card-0')).toBeInTheDocument()
    vi.advanceTimersByTime(5000)
    expect(screen.getByText('card-1')).toBeInTheDocument()
    vi.advanceTimersByTime(5000)
    expect(screen.getByText('card-0')).toBeInTheDocument()
  } finally { vi.useRealTimers() }
})
it('moves on swipe left and right', () => {
  render(<Carousel itemCount={3} renderItem={(i) => <div>card-{i}</div>} autoPlayIntervalMs={10000} />)
  const region = screen.getByTestId('carousel')
  fireEvent.touchStart(region, { touches: [{ clientX: 100 }] })
  fireEvent.touchEnd(region, { changedTouches: [{ clientX: 40 }] })
  expect(screen.getByText('card-1')).toBeInTheDocument()
  fireEvent.touchStart(region, { touches: [{ clientX: 40 }] })
  fireEvent.touchEnd(region, { changedTouches: [{ clientX: 100 }] })
  expect(screen.getByText('card-0')).toBeInTheDocument()
})
it('hides controls for a single item', () => {
  render(<Carousel itemCount={1} renderItem={() => <div>only</div>} />)
  expect(screen.getByText('only')).toBeInTheDocument()
  expect(screen.queryByTestId('carousel-prev')).not.toBeInTheDocument()
  expect(screen.queryByTestId('carousel-dot-0')).not.toBeInTheDocument()
})
it('clears timer on unmount without warnings', () => {
  vi.useFakeTimers()
  try {
    const { unmount } = render(<Carousel itemCount={2} renderItem={(i) => <div>card-{i}</div>} autoPlayIntervalMs={1000} />)
    unmount()
    expect(() => vi.advanceTimersByTime(5000)).not.toThrow()
  } finally { vi.useRealTimers() }
})
```

### Task 2: Home queue integration under NOW-NEXT

**Files:**
- Create: `src/components/HomeQueueCarousel.tsx`
- Modify: `src/screens/HomeScreen.tsx`
- Modify: `src/styles.css`
- Test: `src/screens/HomeScreen.test.tsx`（追記、既存ファイルに3件追加）

**Interfaces:**
- Consumes: Task 1の `Carousel`（`itemCount`, `renderItem`, `autoPlayIntervalMs`, `ariaLabel` のみ使う）、既存 `CoverImage`、`entryKey`・`selectNowAndNext`・`resolveEntry` 相当の予定解決
- Produces: `export type QueueItem = { key: string; title: string; cover: string | null; meta: string; progressPct: number }` と `export default function HomeQueueCarousel({ items }: { items: QueueItem[] })`。`items.length === 0` は `null`、`=== 1` は `Carousel itemCount={1}`（ controlsなし）。`section` は `data-testid="home-queue-carousel"`。
