# 仮想全国ランキング 設計書（2026-10-18）

## 1. 背景・目的

- ホームの日替わり名言だけでは学習意欲が上がらないという課題がある。
- 他人との比較による競争心でやる気を引き出す「仮想全国ランキング」を追加する。
- サーバーなし・無料・ローカル完結を維持する（PWAの現行構成を変えない）。

## 2. 非ゴール

- SFC志望者リーグは作らない（2026-10-18 の判断で廃止）。順位は一般リーグ一本。
- ホーム画面下バー（今日の計画／追加／調整AI／設定）には何も追加しない。
- 本物の他人との通信対戦はしない。ランキング相手はすべて仮想。
- 仮想であることを隠さない（実在偽装はしない）。

## 3. 母集団モデル（20万人・模試級）

- 母集団サイズ N=200,000（進研模試級の規模感）。個人を20万人分保持せず、分布モデルで持つ。
- 分布の骨格（出典つき）：
  - 高校生全体：平日学校外 平均84.4分（文科省）
  - 難関大合格者：定期テスト前で平日約3.6h・休日約7.0h（ベネッセ教育総合研究所、大学生130人調査）
  - 受験生の目安：平日4〜5h・休日8〜10h、高3夏は10h〜（代々木ゼミナール・坪田塾コラム）
  - 総量目安：国公立3,000h〜、私立2,000〜3,000h（坪田塾）
- 上記を平日2〜6h・休日5〜10h中心の対数正規分布に写像し、アプリ内の日次ページ数に換算する係数を定義する。
- 体験談（SFC公式合格体験記・宅浪記など）は分布には使わず、ライバルの属性（部活・予備校・浪人・AO型など）やセリフの味付けにのみ使う。
- 出典一覧をアプリ内「根拠」表示に列挙する。

## 4. 順位計算

- 全体順位は分布から解析的に算出（母集団シミュレーション不要・軽量）。
- 近傍の攻防だけ精密シミュレーション：順位が近い±30人をサンプリングし、日付シードの乱数でその日の積み上げを決定的に生成（再表示でブレない）。
- 各ライバルに生活リズム（朝型・夜更かし追い込み型など）を持たせ、1日の積み上げ曲線に沿って記録を伸ばす。
- 偏差値表示：母集団平均50・標準偏差10に換算（例：偏差値58.3・前回比＋1.2）。
- 更新タイミング：ページ記録時に即再計算＋表示中は1分タイマーで再計算。

## 5. UX

- 入口：ホーム画面本体に「仮想全国ランキング」カードを追加（下バーは触らない）。タップで専用画面へ。
- 専用画面：全体順位（○人中 ○位）・偏差値・近傍30人リスト・「あとXページで○○を抜く」リーチ表示。
- 抜きつ抜かれつ検出：順位入替時にトースト（「○○さんを抜いた！」「○○さんに抜かれた…」）＋近傍メンバー自動入れ替え。
- 月1回「全国模試ウィーク」：毎月第1週（月〜日）に順位確定・偏差値表・到達度目安（S判定等の合否判定は付けない）のイベント化。
- 表記はすべて「仮想全国ランキング」とし、実在と誤認させない。

## 6. データ・保存

- サーバー送信なし。新規保存は端末内のみ（ライバル生成シード・表示設定など）。
- 個人情報・本名は一切扱わない。ライバル名は「神奈川の高3」等の匿名属性のみ。

## 7. テスト

- 純粋関数（分布→順位・偏差値換算、近傍サンプリングの決定性）の単体テスト。
- 画面テスト：カード表示、記録時の順位更新、抜去トースト、模試ウィーク表示。
- 既存全テストのグリーン維持＋ビルド成功。

## 8. リスク

- 「作られた順位」と分かると冷める可能性 → 仮想明示＋週次リーグ組替え・模試ウィークでマンネリ防止。
- 推定値のライブ偽装に見える恐れ → 文言は「推定」を基本とし、断定的な全国実況表現は使わない。
