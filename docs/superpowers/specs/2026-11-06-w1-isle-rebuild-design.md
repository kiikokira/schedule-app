# W1浮遊島フルリビルド（画像準拠・Blender・固定視点）設計書

日付: 2026-11-06 / 対象: ワールド1のみ一から作り直し / 画像2枚準拠（浮遊島＋マリオ式進行表示）
前提: 8ステージ数維持・セーブ互換破棄可・Blender＋固定視点・フル再現・地形優先・方向ズレなし

## §1 目標・非目標・成功条件（承認済み）

目標: 添付画像と同型の浮遊島をBlenderで一から作り直す。
上段テラス（石像・干し草・木柵牧場・東屋・岩山）＋下段テラス（中央石畳ループ・井戸・ホビット村・川）
＋崖2段＋川（崖洞窟滝→丸太→赤橋→海）＋桟橋・石橋アーチ・赤橋を再現。
8ステージ制・円形停止点の遊びは維持し、進行表示はマリオ式に更新。

非目標:
- W2〜W9改修なし
- `RpgWorld3d`全世界共通基盤の大改造なし、新規ライブラリなし
- Draco圧縮なし、水泳なし、昼夜・天候なし

成功条件:
1. 全体俯瞰で画像と一目で同型と分かる（自然形・ハート型禁止）
2. 全停止点で中心停止・接地、青黄/赤黄/黒黄＋先道半透明で進行が分かる
3. 道外不出・橋階段接地
4. `npm run build`成功＋グラフ/接地テストPASS
5. スマホ操作（D-pad/タップ）維持

## §2 アーキテクチャ（承認済み）

```text
Blender source（新規 world1_isle_source.blend）
  → GLB（world1_isle.glb、1K以下テクスチャ埋込）
  → public/rpg/配置 + world1_v3_graph.json（単一座標源）
      ├─ rpgW1Stops v3派生（stop_<nodeId>・半径・stage対応・canEnter）
      ├─ RpgWorld3d W1分岐（台座生成・接地・青黄/赤黄/黒黄＋先道半透明）
      └─ 進行流用→置換（w1CanEnter/normalize・保存v2キー＋旧移行）
```

- `buildWorld1Terrain`現行TS地形は廃止、W1のみBlender参照に切替（W2〜9不変）
- カメラは斜め俯瞰固定: ドラッグ旋回・ピンチ拡縮を無効化（タップ選択・D-pad/WASD・追従は維持）
- 失敗時は旧v2グラフへフォールバックせず生成中止＋エラー表示（中途半端な島を出さない）

## §3 地形・島シルエット（承認済み・改訂2回）

- ハート・円・四角など幾何形は使わない
- 地形に合った自然形: 等高線に沿う海岸線、入江・張り出し・くびれ、海岸線・崖高さに変化
- 上段・下段の2段テラス構成＋側面崖2段（横縞岩肌）＋底面スカート（逆円錐・下面閉じ）
- 外洋・遠景なし: 浮遊島単体で完結、落下防止は見えない壁ではなく崖で遮る
- 地形優先: まず土台・崖・川床の接地を固め、建物は後付け。浮遊・埋没は全点テストで0にする

## §4 道・川・橋（承認済み）

- 道: テラスに沿う石畳ループ、勾配は階段・坂で接続し全区間接地。次挑戦より先は半透明化（透過マテリアル、歩行可否は変えない）
- 川: 上段洞窟滝→渓流→丸太橋→下段→赤橋→海へ落水。川床掘り＋水面リボン、滝は白泡＋飛沫
- 橋: 石アーチ（上段）、赤木橋2本（下段・海側）、桟橋（南・海に突き出し）。全て幅は道と一致・両端接地assert

## §5 ランドマーク・デコール（承認済み）

- ホビット村（南・かやぶき3軒・丸窓丸戸）、井戸（下段中央・屋根付）、石アーチ門・石像（上段・守護像）、干し草俵、木柵牧場
- 樹木（広葉・針葉混植・崖縁避け）、岩・草・花（黄色小花を点在）
- 素材: Kenney Nature Kit優先＋オリジナル低ポリ、リアル系PBRは使わない（1世界1アートスタイル）
- 配置は道・停止点を避け、視認性のため高木は北・東に寄せる

## §6 グラフ・進行・停止点（承認済み）

- 新`world1_v3_graph.json`: 画像準拠にノード再配置（上段5・中段6・下段5想定・計16／パス17前後）。旧v2座標は破棄
- 8ステージ割付（仮、Blender配置時に確定）: S1村入口→S2井戸→S3石橋→S4上段牧場→S5石像→S6滝裏→S7赤橋→S8桟橋守護
- 台座: 全16点に円形3層（外環＋敷石＋中央）
  - クリア済み: 青丸＋黄外環
  - 次挑戦（解放済み未クリア先頭）: 赤丸＋黄外環
  - その先（ロック中・未来）: 黒丸＋黄外環（従来灰は廃止）
  - 先道半透明と連動、色＋形＋透過の3重表現で色覚非依存
- 保存: `schedule-app-rpg-progress-v2`新キー、旧v1は初回のみ吸収移行（失敗時は最初から）

## §7 カメラ・操作・UI（承認済み）

- カメラ: 斜め俯瞰固定（画像視点）。ドラッグ旋回・ピンチ拡縮は無効、追従＋全体表示のみ。全体表示で島全景が丸く収まる画角に固定
- 操作: D-pad/WASD・タップBFS・Enter決定は維持。各円中心でdwell停止、locked/未来点には手前で停止
- UI: 凡例を青黄・赤黄・黒黄＋先道半透明に更新。W2〜9表示・動作は不変

## §8 エラー・テスト（承認済み）

- エラー:
  - 地形NaN・ノード欠落時は該当台座のみ非生成で進行継続
  - GLB欠落時はW1選択不可表示（旧島フォールバックなし）
  - 透過・黄環のreduced-motion時は点滅抑制、停止・待機の意味は維持
  - locked判定は表示層だけでなく移動・決定・クリア記録の全層で実施
- テスト:
  - 純粋（`rpgW1Stops` v3）: 16点・ID規則・半径・接続自動算出・stage対応、全点canStop・locked手前停止・旧移行
  - 3D/接地: 全点埋没浮遊なし・橋両端接地（既存burial/float条件流用）
  - UI/挙動: 3色黄環・先道半透明・固定視点で全体収束・タップdwell・D-pad待機・locked不可
  - 回帰: 既存RPG群＋`npm run build`成功
  - 手動: 円形配置・丸く見える・中心停止・道路歩行・道路外不出・3色黄環・橋階段接地・全景表示・スマホ操作・既存機能無傷

## 移行・互換性

- 旧W1セーブ（w1-stage-* / grass-stage-*）は初回のみv2へ吸収、失敗時は最初から
- `world1_v2_graph.json`は残置し参照切替のみ（削除しない）
- W1専用コードは他ワールドに影響しないこと。`WORLD3D_CONFIG`のW2〜9定義は不変
