# 仮想模試 成績表コレクション 設計書（2026-10-20）

## 1. 背景・目的
- 月1回「全国模試ウィーク」の表示が単発で終わり、成長実感・ご褒美感が薄い。
- 過去の偏差値推移と称号バッジで「集めて眺める」楽しさを足し、やる気を引き出す。

## 2. 非ゴール
- 下バー（今日の計画／追加／調整AI／設定）には何も追加しない。
- S判定等の合否判定は付けない（A〜E目安まで）。
- 本物の他人との通信対戦はしない。表記はすべて「仮想」。
- サーバー送信なし。新規保存は端末内のみ。

## 3. データ
- localStorage `schedule-app-mock-history`: [{ym:"2026-10", rank, deviation, pages}]
- 毎月第1週（1〜7日）の初回表示時に当月分を1件だけ追記。キー ym で重複防止。
- 順位計算は既存 totalPagesToRank / rankToDeviation を流用（src/lib/ranking.ts）。

## 4. UX
- 入口：RankingScreen 内の模試セクションを拡張（下バー不変）。
- グラフ：X=年月、Y=偏差値の折れ線（ProgressChart と同型、chart.js）。0件時は「来月の第1週で初記録！」。
- 前回比：グラフ下に矢印1行（例 前回比 +1.2）。
- バッジ棚 data-testid="mock-badges"：初陣／3連続受験／自己ベスト／ジャンプ賞(+3)／上位10% の5個。未獲得はグレー＋条件文。

## 5. テスト
- 純粋関数：履歴追記の重複防止・月連続判定・バッジ判定の単体テスト。
- 画面：履歴グラフ・バッジ棚・空状態・既存テストのグリーン維持＋ビルド成功。
