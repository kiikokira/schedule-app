# W1草原ジオラマ高品質化 — 設計書（パイロット）

- 日付: 2026-11-07
- 対象: W1草原のみ先行（`world1_grassland`／`world1_isle`系の置換候補を1本に絞る）
- 承認済み: §1〜§8（チャットで逐次承認）
- 非対象: Home・スケジュール管理・ランキング・設定・RPG・ワールドマップ・Blender連携の既存動作。RPGへの反映は本設計承認後に別途承認を得て実施。

## 背景・目的

現行W1は「低ポリの組み合わせ＋単色マテリアル中心」（地形top約2000〜3800面、構造物はBox／Cone／Icosahedron変形、地面のみ512px縮小の写真系テクスチャ）で、プリミティブ感が残る。
参考画像（スタイライズド等角ジオラマ：面取り赤茶地層クリフ、厚みある草地、白い遊歩道、段々滝、広葉樹／多層針葉樹、密集小物）の一般的ビジュアル特徴を取り入れた**独自オリジナル**のジオラマへ作り替える。特定作品の複製はしない。

## 前提・制約（§1 承認済み）

- Blender 5.2（`C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`）をバックグラウンド生成・確認に固定。PATH未登録のためフルパス起動。
- 経路グラフのxz・トポロジーは固定。地形変更後は `y = H + 0.05` で追従のみ（表示と移動論理の一致をテストで担保する現行方式を維持）。
- GLBは目標3MB・上限5MB・「アプリが重くならない＋ラグくならない」実測が最終判断。現行2MB assertはW1パイロット用に緩和する（要テスト更新）。
- アートスタイルは参考画像優先のスタイライズド手描き風に統一。写真系PBR（ambientCG／Polyhaven）はW1パイロットでは使わない（`ASSETS.md`の混ぜない規則を遵守）。
- 素材はCC0＋自作のみ。Kenneyは樹木本体ではなく小構造物（柵・橋・足場等）に限定。
- CYCLESで中間・完成レンダーを確認し、Three.js（RpgWorld3d）表示と両方で検証する。

## 検討した進め方

- A. フル再構築（採用）: 地形テラス化＋岩草木の新規造形＋手描き1024＋高密度散布。最良・工数大。
- B. 差分強化（不採用）: 速いが地形の積み木感が残る。
- C. Kenney全面活用（不採用）: 統一は容易だが独自性・造形密度が中で要求未達。

## 設計

### §2 地形・岩

- 楕円島＋湾＋2テラス＋逆円錐スカートの構成は維持（ゲーム進行・景観の土台）。
- テラス縁に段差・張り出し・角欠けを付け、輪郭を不規則化する。
- 岩肌は赤茶地層系：横方向の地層ライン、割れ目、大小の岩層、岩間隙間、凹凸面をbevel＋頂点色変化＋手描きテクスチャで表現。単純な多角形押出しは禁止。
- 草地端から垂れ下がる植物、岩棚の段差・張り出しを設ける。
- 全岩に形状・色のばらつきを持たせる。

### §3 草地

- 単なる緑平面は禁止。厚み＋端オーバーハングで立体化し、地形凹凸を付与する。
- 表面色変化、苔、長短の草束、細い垂れ植物、小花・葉を組み合わせる。
- 表現は頂点色＋手描き1024テクスチャ。

### §4 樹木

- 球体3個並べ・単一円錐は禁止。
- 広葉樹：幹＋複数枝＋大小の葉塊＋色違い葉＋自然な樹冠輪郭。各3種以上のバリエーション。
- 針葉樹：多層の枝葉を持つ立体モデル。各3種以上のバリエーション。
- 樹木本体は新規造形。Kenneyは柵・橋・足場等の小構造物に限定。

### §5 テクスチャ・マテリアル

- 写真系PBRは使わない。スタイライズド手描き1024を素材別に作成。
- 岩：地層・亀裂・細かな凹凸。草：濃淡・苔・草模様。
- Base Color／Normal／Roughness／AOの4種を素材別に作成しGLBへ正しく埋め込む。Roughness全面均一は禁止。
- 512px縮小の運用はW1パイロットでは行わない（原本＋GLB埋込の二重管理は維持）。

### §6 小物散布

- 岩・低木・花・草・苔（紅葉色含む）を高密度で配置。機械的整列は禁止し、位置・回転・scale・色にばらつきを持たせる。
- 道路2m・川2m・ランドマーク回避のクリアランスは維持。
- 大量草はインスタンス化し、描画コール・トライアングル予算内で負荷対策する。
- 散布総数は100件以上を目安とする（現行40件の2倍以上）。

### §7 ライティング・カメラ

- 斜め上からの等角（アイソメトリック）構図、島全体が見える正方形フレーム（1080x1080）。
- 柔らかいスタジオライティング、自然な影、接触部分の陰影、明るく豊かな色彩。
- BlenderレンダーとThree.js表示の両方で確認する。

### §8 成果物・完成判定

成果物：ゲーム用GLB／編集用blend／テクスチャ一式／Blender生成スクリプト／ワールド配置JSON／コリジョンデータ／OpenCodeへの実装説明書／完成レンダリング画像。中間レンダーを参考画像と比較し不足を修正する。

完成条件（全満たすまで完成としない）:

1. 岩が積み木に見えない
2. 草地が平面に見えない
3. 樹木が単純球体の集合に見えない
4. 表面に十分な質感と凹凸がある
5. 小物の密度が十分にある
6. 明るさ・影・色彩が統一されている
7. カメラから見た全体バランスが自然である
8. GLBにマテリアルと必要なテクスチャが正しく含まれている

検証：GLB内images／materials／meshesのJSON検証、クリアランスassert、グラフ整合テスト、`npm run build`成功。RPG本体への配線変更は別途承認後に実施する。

## Rulings（本設計での判断）

- Ruling: 参考画像優先のスタイライズド手描きに寄せ、本文の2048写実PBR要求は不採用 — 画像と本文が衝突し画像優先が承認されたため。誤り時のコストはテクスチャ作り直し。
- Ruling: GLB上限を「目標3MB・上限5MB・実測ラグなし」に緩和 — 高密度化と2MB assertが両立しないため。誤り時のコストはモバイル最適化の再作業。
- Ruling: Blender 5.2に固定 — 最新機能（Geometry Nodes等）の利用と承認に基づく。誤り時のコストは3.4への差し戻し。
- Ruling: 樹木本体は新規造形・Kenneyは小構造物限定 — 独自性と参考画像の樹形再現のため。誤り時のコストは差し替え工数。
