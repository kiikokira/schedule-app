# 統合シーズン制（RPG＋リーグ）設計書

日付: 2026-10-21
状態: 承認済み・実装前

## 1. 目的

- ソロ継続（RPG）と競争（リーグ）を1つのシーズンptに統合し、やる気を長期維持する。
- 完全オフライン（GitHub Pages + IndexedDB/localStorage）を維持する。
- ホーム画面フッター（今日の計画 / スケジュールで参考書を追加 / 調整AI / ＋参考書を追加 / 設定）に新規欄を追加しない。

## 2. 制約（確定事項）

- 1シーズン = 4週間（28日、28節）。毎日が1節。
- eFootball式：デイリーptで順位が毎日変動。直接対決の星取表あり。
- 実況なし：実況文・通知文は作らない。順位表と前日比▲▼のみ。
- Div10スタート。昇格でDiv9→…→Div1へ。上に行くほど難化。
- 既存books/recordsは読み専。新規4テーブルのみ追加。

## 3. 全体構成

- シーズンpt一本化：RPGのEXPとリーグptの元データは同じpages（`scoreActivityOnDate`）。
- TodayPlanの記録 → EXP/pt加算 → RPGレベルUP＋リーグ順位変動。
- 画面は既存流用のみ：
  - Home「仮想全国ランキング」カードにシーズンバナー追記（Div・順位・残り節）。
  - Ranking画面に「全国 / リーグ / RPG」タブ追加。
  - MyPageにLv・Div・図鑑表示を追記。
  - 新規ルート・フッター追加なし。

## 4. リーグ仕様

- 8人制（自分＋AIライバル7人）。Div10〜Div1の10段階。
- 昇降格：28節終了時に上位2人が昇格、下位2人が降格。Div10は降格なし、Div1は昇格なし。
- 順位：その日のpages（デイリーpt）累計ではなく「シーズン累計pt」で順位付けし、毎日変動表示。前日比▲▼表示。
- 星取表：その日のライバル7人との直接対決（pages比較）で勝ち数を記録。
- AIライバル：`seasonId + div + day`をseedにした決定的疑似生成。完全ローカル、再現性あり。
- 難易度逓増：
  - Div10平均20p/日、Div5平均60p/日、Div1平均150p/日目安。
  - 上位Divほどばらつき小（安定して強い）。
  - 具体数値は実装時に`lib/seasonRivals.ts`に定数として集約。

## 5. RPG仕様

- TodayPlanの記録=討伐。10ページ=100EXP基準、連続日数でコンボ倍率（例：3日以上×1.2、7日以上×1.5）。
- LvUPで称号付与。装備・図鑑は既存バッジ流用で拡張（鉄→銀→金）。
- ボス戦=週末の模試ウィーク（既存mockHistory連動）。勝利でボーナスEXP。
- EXPとリーグptは同一元データ、表示用換算のみ別。

## 6. データ設計（Dexie追加）

- `seasons(id, startDate, div)`：シーズン管理。id=`YYYY-MM-DD`開始日。
- `seasonDays(date, pages, rank, wins)`：日別確定記録。日跨ぎで1回だけ確定。
- `rivals(seasonId, name, type, strength)`：AIライバル定義。seed再生成可能。
- `player(div, exp, level)`：現在Div・累計EXP・レベル。単一行。
- 既存`records/cycleRecords`は参照のみ。重複記録なし。

## 7. 画面遷移

- Home → 順位を見る → Ranking（リーグタブ既定表示に切替可）。
- Home → マイページ → MyPage（Lv・Divカード）。
- Ranking内タブ：全国（既存）/ リーグ（新規順位表＋星取）/ RPG（レベル・クエスト）。
- 戻るボタンは既存onBack流用。

## 8. エラーハンドリング

- 日付不正・DB未読込時はリーグ表示をスキップし、既存全国表示のみ出す。
- シーズン跨ぎ判定は`todayStr()`基準。過去日の遡及確定はしない。
- seed生成失敗時は固定弱ライバルにフォールバック。

## 9. テスト方針

- `lib/seasonLeague.test.ts`：28節確定・昇格2/降格2・Div10降格なし・Div1昇格なし。
- `lib/seasonRivals.test.ts`：同一seedで同一生成、Div1平均＞Div10平均。
- `lib/seasonExp.test.ts`：pages→EXP換算、コンボ倍率。
- 既存Ranking/MyPage/Homeのテストは壊さない。フッターに新規ボタンがないことをテストで担保。

## 10. 対象外

- 実況文・プッシュ通知・サーバー対戦・課金・シーズンパス。
- 物語モード（C案）は本spec対象外。将来拡張。
